# KickMate – UX/UI Design Project

## Project Description
KickMate is a mobile app concept that helps people find, join, and organize nearby football matches.

## Problem
Players often struggle to find enough people for football matches. Organizing games through group chats can be difficult.

## Solution
KickMate allows users to:
- Find nearby football matches
- View match details and available places
- Join existing matches
- Create new matches

## Design Process
1. User research and interviews
2. Information architecture
3. Wireframes
4. Interactive Figma prototype
5. Usability testing
6. Design improvements

## Results
The prototype was tested with users. Feedback helped improve navigation, match information, and match creation.

## Project Status
Final UX/UI prototype and presentation completed.
